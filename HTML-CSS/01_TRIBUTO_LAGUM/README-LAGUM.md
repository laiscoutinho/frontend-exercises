# 🎵 Tributo à Banda Lagum

Projeto frontend simples desenvolvido como **exercício prático de HTML e CSS**.

O objetivo é **validar e aplicar conceitos básicos**, como uso de tags semânticas, estruturação de conteúdo e estilização com propriedades essenciais de CSS.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

---

## 🎯 Objetivo

- Praticar a estruturação de páginas
- Aplicar tags HTML na prática
- Explorar propriedades básicas de CSS

Projeto pequeno, focado exclusivamente em aprendizado.
