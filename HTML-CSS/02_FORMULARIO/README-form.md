# 🎵 Formulário

Projeto frontend simples desenvolvido como **exercício prático de HTML e CSS**.

O objetivo é **aplicar e consolidar conhecimentos sobre formulários em HTML,**, utilizando como referência a estrutura e organização de formulários do Google Forms, adaptados para uma página web própria.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3

---

## 🎯 Objetivo

- Praticar a criação de formulários HTML
- Aplicar corretamente inputs, labels e validações básicas
- Estruturar uma página de formulário inspirada no Google Forms
- Explorar propriedades essenciais de CSS para organização visual

Projeto pequeno, focado exclusivamente em aprendizado.
