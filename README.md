# 📚 Projetos Frontend

Repositório dedicado a **pequenos projetos frontend**, desenvolvido com foco em **prática contínua, consolidação de fundamentos e evolução técnica**.

Todos os projetos [aqui](https://github.com/laiscoutinho/frontend-exercises.git) presentes fazem parte dos meus **estudos no curso Hora de Codar**, com uma abordagem hands-on para acelerar o aprendizado e construir repertório real de código.

---

## 🚀 Tecnologias exploradas

Os projetos utilizam, de forma progressiva:

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- TypeScript

Cada projeto foca em conceitos específicos, boas práticas e organização de código.

---

## 🧪 Objetivo do repositório

- Treinar fundamentos de frontend
- Experimentar novas abordagens e soluções
- Evoluir gradualmente em complexidade
- Criar um histórico claro de aprendizado

Este repositório é **100% educacional**.
